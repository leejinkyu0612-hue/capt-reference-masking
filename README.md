# capt-reference-masking

Code, prompts and logged outputs for a study of how reference-text context and verbatim instructions affect the masking of mispronunciations by speech recognizers and audio LLMs on read L2 English speech (speechocean762 test split).

- Data: speechocean762 (CC BY 4.0) is downloaded from Hugging Face (mispeech/speechocean762). Audio is not redistributed here.
- PREREGISTRATION.md: analysis plan fixed before the main run.
- prompts.py: fixed prompt wording.
